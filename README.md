# Global Data Center Carbon Emissions Estimation

This repository contains the official research paper and modeling documentation for our project submitted to the **High School Mathematical Contest in Modeling (HiMCM)**, where our team was awarded **Honorable Mention**.

## Project Overview
* **Objective:** To estimate and evaluate global data center energy consumption, power usage effectiveness (PUE), and corresponding carbon emissions.
* **Core Approach:** Decomposed the components of modern data centers (specifically separating CPU and GPU energy costs) and built a multi-factor mathematical model to calculate environmental impacts.
* **Result:** Successfully derived predictive carbon emission curves and proposed strategic optimizations for green data center operations.
